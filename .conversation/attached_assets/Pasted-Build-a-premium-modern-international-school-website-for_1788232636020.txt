Build a premium, modern international school website for a fictional but realistic school in Abuja, Nigeria called **Westbridge International Academy (WIA)**.

The website should feel like a real top-tier Abuja school website — sophisticated, trustworthy, warm, modern, and highly polished. Do NOT make it look like a generic AI-generated school template.

## 1. Brand positioning

Westbridge International Academy is a premium independent international school in Abuja serving students from Early Years through Secondary School.

Brand personality:

* Excellent but approachable
* International but distinctly African
* Modern but not futuristic
* Academic but human
* Premium without being flashy
* Safe, nurturing, ambitious and community-oriented

Use realistic Nigerian/Abuja context throughout the website.

Create a refined visual identity using:

* Deep forest green as the primary brand colour
* Warm ivory/off-white backgrounds
* Muted gold as a subtle accent
* Charcoal/dark green typography
* Generous whitespace
* Elegant typography
* Subtle borders and shadows
* Sophisticated photography

Avoid excessive gradients, excessive rounded cards, neon colours, glassmorphism, and generic SaaS aesthetics.

## 2. Technology

Build the website as a production-quality responsive web application.

Use:

* React
* TypeScript
* Tailwind CSS
* Lucide React icons
* Smooth, subtle animations
* Clean reusable components
* Accessible semantic HTML

Keep the code modular and maintainable.

Create reusable components for:

* Navbar
* Hero
* Buttons
* Section headers
* Cards
* Statistics
* Testimonials
* News/articles
* Footer
* Mobile navigation
* Admissions CTA
* Contact forms

Do not put the entire website into one huge component.

## 10. Design quality

This is extremely important.

The website must look like it was designed by a world-class digital agency.

Use:

* Excellent typography hierarchy
* Strong spacing
* Editorial layouts
* High-quality image treatment
* Subtle motion
* Smooth hover states
* Carefully designed buttons
* Responsive layouts
* Consistent grid system
* Strong mobile experience

Animations should be subtle and purposeful:

* Fade/slide reveals
* Image parallax where appropriate
* Gentle hover movement
* Smooth navigation transitions

Respect prefers-reduced-motion.

Do NOT:

* Overuse animations
* Use random gradients
* Use huge rounded rectangles everywhere
* Fill every section with cards
* Use placeholder lorem ipsum
* Create fake dashboards
* Make it look like a startup landing page
* Use excessive emojis

## 15. Final quality-control requirement

Before considering the task complete:

1. Run the application.
2. Check every page.
3. Check the browser console.
4. Fix all application errors.
5. Check for broken images.
6. Check all links and buttons.
7. Test mobile responsiveness.
8. Test forms and interactive components.
9. Check for horizontal overflow.
10. Check accessibility basics.
11. Remove unused imports and obvious warnings.
12. Make sure there are no duplicate JSX elements or malformed components.
13. Make sure the production build succeeds.

Most importantly:

**Do not stop after generating the code. Actually run and inspect the website, identify problems, fix them, and verify the final result.**

The final result should feel like a real premium international school website based in Abuja — not an AI demo.
